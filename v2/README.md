# Vegas信号系统 V2（全新重写）

本目录是独立重写版。现有根目录代码与默认分支保留，不把旧版逻辑直接复制进 V2。

## 固定边界
- 行情数据源：只使用 Bitget；不自动切换雅虎财经或其他行情源。
- 扫描对象：配置中启用且 Bitget 实际支持的合约品种；不可用要明确报错，不能伪造行情。
- 方向周期：当前配置为 4H。
- 入场观察周期：1H、2H，各自独立判断。
- 中锋：EMA144；已完成 K 线的 high/low 覆盖 EMA144 才算触碰。
- 过滤线：EMA12；触碰中锋只启动/维持观察，不单独推送。
- 正式信号：方向门槛允许后，观察中的完整 K 线收盘价高于 EMA12 才能做多信号，低于 EMA12 才能做空信号，等于则无信号。
- 通知：只推送正式信号；观察状态、触碰事件不推送。
- 不自动下单，不把回测功能混进信号系统。

## V2 模块顺序
1. Bitget 行情适配器：请求、响应校验、时间戳、完整 K 线过滤。
2. 指标计算：EMA144、EMA12、4H 方向判断。
3. 规则引擎：方向门槛、中锋触碰、观察状态、过滤线收盘确认。
4. 状态与去重：观察状态跨扫描保存；按品种/周期/已完成 K 线时间戳去重。
5. 输出与通知：记录每轮扫描结果；只通知新出现的正式信号。
6. 自动测试：行情异常、未完成 K 线、方向不符、触碰不通知、EMA12 确认、多周期独立、持久化和重复通知。

## 运行原则
先让规则引擎和测试独立通过，再接 Bitget；接好后先运行一次真实行情扫描，核对结果，再接入定时任务。V2 未通过验证前不替换默认分支的运行版本。
