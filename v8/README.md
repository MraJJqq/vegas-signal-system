# VEGAS V8 信号系统

## 正式规则
1. 行情来源：Bitget USDT 合约。
2. 自动扫描频率：每小时一次。
3. 扫描周期：仅 1H。
4. 中锋：EMA144、EMA169。
5. 红峰：EMA576、EMA676。
6. 触碰条件：已收盘的 1H K 线最高价与最低价覆盖中锋或红峰区域内任意一条均线值，即进入观察期。
7. 观察期：不设时间限制；触碰后持续观察，直到正式信号出现。
8. 过滤线：EMA12。
9. 正式信号：触碰发生后，后续已收盘的 1H K 线收盘价位于 EMA12 上方或下方任意一侧，即触发正式信号。触碰所在的同一根 K 线不同时作为正式信号；收盘价恰好等于 EMA12 时继续观察。
10. 正式信号触发后，本轮观察结束；之后再次触碰中锋或红峰区域时，重新进入观察期。
11. 扫描池：沿用当前 V8 扫描器中的品种配置。
12. 通知方式：ntfy；通知标题和两个类别标题始终保留，类别为“核心能源”和“美股巨头”。
13. 通知名单规则（北京时间 UTC+8）：
    - 每天第一次扫描：按现有模板列出当天所有符合条件的品种。
    - 当天后续扫描若与上一次结果相同，或只有品种减少、没有新增：两个类别标题下分别显示 `▰ No change ▰`，不显示品种名称。
    - 当天后续扫描只要出现至少一个相对上一次扫描新增的品种：恢复现有模板，列出本次扫描全部符合条件的品种。
    - 每次扫描仍然推送；每次成功推送后保存本次名单，供下一次比较。跨日后重新按当天第一次扫描处理。
14. 扫描失败时：不发送扫描完成通知。
15. 每日结果重置：以中国时间（UTC+8）为准，只将当天正式信号收盘 K 线产生的信号放入当日通知；前一天正式信号不会进入次日通知。

## 配置
在 GitHub Actions Secrets 中配置：
- `V8_NTFY_TOPIC`
- `V8_NTFY_TOKEN`

密钥不写入代码。V8 使用独立的 `v8/` 目录与独立工作流。
