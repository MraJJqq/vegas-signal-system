# V1 交易系统

**正式名称：V1 交易系统**  
**简称：V1**

本目录独立保存 V1 交易系统代码，与 Vegas 信号系统 V3 隔离。更名只调整系统名称和文件命名，不改变任何已确认的 Vegas 交易规则。

## 主程序

- `v1_trading_system.py` — V1 交易执行与风险框架

## 规则边界

- 按信号 K 线收盘价入场；只使用已收盘 K 线。
- 观察状态不设超时。
- 逐仓保证金预算：普通仓 10 USDT，反转试错仓 5 USDT。
- 加仓必须有新的有效 Vegas 信号，每次预算减半。
- 反转时，原趋势仓减至 20%，并建立 5 USDT 反向试错仓；试错仓不主动平仓。
- 不设置初始账户资金，不计算账户收益率。
- 小缺口合成的 K 线必须标记。
- 不添加或改写 Vegas 信号规则；信号由独立的 V3 系统提供。
