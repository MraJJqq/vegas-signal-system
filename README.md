# VEGAS AI TRADING — V1 交易系统与 V3 信号系统

本仓库包含两个相互隔离的子系统：

- **V1：交易系统** — `backtest_system/`，负责按已确认信号模拟入场、加仓、反转、风险记录和历史回测。
- **V3：信号系统** — `v3/`，负责读取 Bitget 4H 已收盘行情、计算 EMA12/144/169/576/676、判断正式信号。

## 隔离与规则保护

- V1 与 V3 代码和运行流程独立；不要将 V1 的回测执行逻辑混入 V3。
