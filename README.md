## 当前唯一版本：V7

- V7 是当前唯一信号系统版本，代码从独立的 `v7/` 目录重新开始。
- V1–V6 已退役，不再作为运行版本或开发基础；旧代码和旧工作流正在清理。

- 只触碰中锋或红峰时不推送；观察状态每天结束后清空，次日重新开始。
- 行情源为 Bitget USDT 合约。

## 规则保护

- 仅使用用户明确确认的 Vegas 规则。
- 不加入 RSI、MACD、布林带、ATR 或其他非 Vegas 指标。
- 未经用户明确批准，不得修改、放宽或重新解释交易规则。
- 正式信号规则未核对完整前，不自行补充触发条件。
