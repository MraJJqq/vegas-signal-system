# VEGAS V9 A股独立扫描系统（原生 1H）

本目录独立运行，不导入或修改美股 V9 的代码、状态或推送流程。

## 核心规则
- 数据源：Baostock 原生 60 分钟 K 线；不把 1H K 线聚合成 4H。
- 指标：EMA12 过滤线、中锋 EMA144/169、红峰 EMA576/676。
- 触发：已收盘 1H K 线的最高/最低价与中锋或红峰区间重叠，进入观察。
- 正式信号：触发后的另一根已收盘 1H K 线收盘价位于 EMA12 上方或下方；等于 EMA12 时继续观察。
- 观察无时间限制；离开触发区域不取消观察；每次观察只产生一次正式信号。
- 不使用 RSI、MACD、布林带、ATR；不自动下单。
- EMA676 至少需要 676 根有效且已收盘的原生 1H K 线。数据不足或异常的股票单独排除并写明原因，不中断其余股票扫描。
- 首次迁移到 1H 时，状态引擎从最近已收盘 K 线开始建立新状态，避免把历史信号当成今天的信号。
- 预定扫描时间为北京时间约 10:30、11:30、14:00、15:00（GitHub Actions 定时可能延迟）；也可手动触发。
- 状态：`v9_cn_a/.signal-state.json`；报告：`v9_cn_a/scan-report.json`；行情缓存：`v9_cn_a/.candle-cache.json`。

## 股票池
`baostock-stock-pool.json` 由 `baostock_pool_builder.py` 从 Baostock 获取在市沪深 A 股，并按近期平均成交额排序选出 2000 只。首次使用或名单缺失时，先运行工作流 **VEGAS V9 A股 Baostock Build 2000-Stock Pool**。
