# VEGAS V9 A股扫描系统

独立目录 `v9_cn_a/`，与美股 V9 `v9/` 分离。不得导入美股目录代码、共享状态文件、报告文件或工作流并发组。

## 扫描触发与通知

- 北京时间每天 07:00–22:00，每小时整点扫描并推送。
- 行情源统一使用 Baostock 的 60 分钟 K 线，按交易日聚合为完整 4H K 线后计算指标；首次拉取约 4 年历史，缓存保留最多 3600 根 1H K 线。
- 通知使用 Bark；当天存在正式信号时，每次扫描推送当天完整信号列表；当天无正式信号则不推送。
- 信号规则：观察期与信号期全部使用 4H K 线。4H K 线与中锋区 EMA144–EMA169 或红峰区 EMA576–EMA676 重叠时进入观察期；之后的已收盘 4H K 线收在 4H EMA12 上方或下方时产生正式信号，收盘价等于 EMA12 则继续观察。观察期无时间限制，触发后离开区域不取消观察。
- 状态：`v9_cn_a/.signal-state.json`
- 报告：`v9_cn_a/scan-report.json`

## 2000 只股票扫描池

- 手动运行 GitHub Actions 工作流 `VEGAS V9 A股 Baostock Build 2000-Stock Pool`，从 Baostock 获取在市沪深 A 股清单，并按近期可用日线的平均成交额降序推荐前 2000 只。
- 名单写入 `v9_cn_a/baostock-stock-pool.json`；每次扫描严格检查名单恰好 2000 只且代码无重复。
- 每小时扫描工作流为 `VEGAS V9 A股 Baostock Scan`；扫描频率与信号K线周期独立，指标和信号判断均基于完整 4H K 线。首次运行前必须先成功构建 2000 只名单。
- 建池和扫描都仅使用 Baostock；腾讯扫描器文件保留但不再由正式定时工作流调用。
- 2000 只候选按流动性排序，不代表买卖建议；数据不可用或 OHLC 异常的股票会从当次有效扫描结果中排除。
