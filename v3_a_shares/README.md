# V3 A股扫描

A股使用独立的扫描范围，不修改美股 V3 扫描逻辑或共享 Vegas 引擎。A股只扫描4H中锋与过滤线，不扫描红峰。

## A股扫描规则

- 周期：4H；只使用已收盘K线。
- 中锋：EMA144、EMA169；方向由收盘价相对中锋区域的位置决定。
- 过滤线：EMA12；价格在中锋区域上方且收盘价高于EMA12，确认LONG；价格在中锋区域下方且收盘价低于EMA12，确认SHORT。
- 观察触发：只由4H K线触碰/进入中锋区域启动；不再把红峰作为观察触发条件。
- 观察期无时间限制；触碰中锋只启动观察，不立即发正式信号。
- 红峰EMA576/EMA676完全不参与A股扫描，也不要求计算或预热。
- A股历史60分钟行情由 BaoStock 提供，使用前复权（adjustflag=2）；固定扫描池为 `universe.json` 中的24只沪深主板股票。
- A股交易时段每日合并为一根完整交易时段K线（上午和下午合计4小时，午休不计入）。这属于A股行情适配方式。

## 历史数据要求

A股扫描最长均线为EMA169，因此至少需要169根完整交易时段K线。少于169根时拒绝计算信号，不会缩短均线周期或用日线冒充4H。实际扫描仍会检查24只股票是否全部成功；任何一只报错都会终止本轮正式推送，避免不完整扫描被当作成功。

## 运行

GitHub Actions workflow: `.github/workflows/ashare-scan.yml`

需要仓库 Actions secret `NTFY_TOPIC`。正式扫描继续使用ntfy每日摘要/去重逻辑。
