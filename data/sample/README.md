# Sample market data

Place one CSV per symbol and timeframe here using the pattern `{SYMBOL_ID}_{timeframe}.csv`.

Examples: `GOLD_4h.csv`, `GOLD_8h.csv`, `GOLD_1h.csv`, `GOLD_2h.csv`.

Required columns: `timestamp,open,high,low,close,volume`.
Timestamps should be parseable dates; values should be numeric. No live data provider is configured yet.
