# Vegas 信号系统 V2

这是独立的新目录，V2 代码只围绕当前确认的新信号规则实现；旧目录不作为 V2 的规则来源。此操作不会删除仓库中已有文件。

## 已确认规则
1. 以已收盘的 4H K 线确认 4H 中锋上穿/下穿 4H 红峰。
2. 交叉后，价格第一次触及 4H 中锋或 8H 先锋，使用这根已收盘的 4H K 线进行确认。
3. 过滤线固定为 EMA12：看涨收盘必须高于 EMA12；看跌收盘必须低于 EMA12。
4. 同一轮交叉最多产生一个正式信号；正式信号只生成提醒，不下单。
5. 数据缺失、指标不可用或 K 线未收盘时，不生成正式信号。

## 参数约定
- EMA12：过滤线
- EMA36：先锋
- EMA144：中锋
- EMA576：暂按仓库原配置中的 large_capital_ema 作为红峰默认值，集中配置在 `config.yaml`，后续可改配置而不改核心代码。
- 交叉确认与回踩确认均使用已完成的 4H K 线。
- 4H 中锋与 8H 先锋两条线中，先被触及的一条触发首次回踩判定；若该首次触及未通过 EMA12 收盘确认，则本轮交叉失效，等待下一次交叉。这是为使“第一次回踩”可执行而采用的保守实现约定。
