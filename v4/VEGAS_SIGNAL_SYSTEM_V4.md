# VEGAS 信号系统 V4 — 规则基准与迁移清单

版本：V4
状态：规则整理完成；代码迁移与验证进行中
原则：不得未经用户明确批准修改、放宽、替代或重新解释 Vegas 判断规则。

## 1. 观察周期
- 只观察 4H 已收盘 K 线。
- 不使用 8H、2H 或其他周期参与 V4 信号判断。

## 2. 均线定义
- 中锋区域：EMA144、EMA169。
- 红峰区域：EMA576、EMA676。
- 过滤线：EMA12。
- 不增加 RSI、MACD、布林带、ATR 或其他非 Vegas 指标。

## 3. 观察触发
出现以下任一情况时启动/维持观察：
- K 线价格范围触及中锋区域（EMA144/EMA169），或收盘价位于该区域；
- K 线价格范围触及红峰区域（EMA576/EMA676），或收盘价位于该区域。
触及区域本身不是正式信号。

## 4. 多空方向与正式确认
- 方向按中锋区域判定：收盘价高于中锋区域上沿为 LONG，低于区域下沿为 SHORT；处于区域内部时不额外推断方向。
- 观察期间，只有已收盘 K 线在对应方向上满足 EMA12 过滤条件，才可确认正式信号：LONG 要求 close > EMA12；SHORT 要求 close < EMA12。
- 观察没有时间限制；不得因横盘或等待时间过长自动取消。
- 启动观察的同一根 K 线不同时确认正式信号。
- 仅使用已收盘 K 线，不允许未来数据或未收盘 K 线参与确认。

## 5. 扫描品种与调度
- V4 首阶段仅恢复美股相关 Bitget USDT 合约扫描及原有补充品种，不运行 A 股扫描。
- 固定扫描池：SPYUSDT、QQQUSDT、SNDKUSDT、NVDAUSDT、AMDUSDT、AVGOUSDT、MUUSDT、TSMUSDT、MSFTUSDT、AAPLUSDT、TSLAUSDT、ARMUSDT、AMZNUSDT、METAUSDT、GOOGLUSDT、ORCLUSDT、PLTRUSDT、COINUSDT、MSTRUSDT、HOODUSDT、XAUUSDT、CLUSDT、BTCUSDT、HYPEUSDT。
- 每小时扫描一次；数据不可用或交易所不支持时，必须明确报告错误，不得静默跳过或伪造信号。
- 行情源优先 Bitget；使用已收盘 4H K 线。EMA676 计算需要足够历史数据。

## 6. 通知与去重
- 通知渠道：ntfy。
- 正式信号确认后进入通知流程。
- 同一根已收盘 4H K 线必须使用稳定信号标识去重，防止重复计为新事件。
- 当天后续摘要可重复列出当天已确认信号，但必须区分“新信号”和“已确认信号摘要”。
- 日期切换后不将前一天信号混入当天摘要；日期按 Asia/Shanghai 自然日划分。

## 7. 工程边界与迁移顺序
- V4 代码独立存放于 v4/；不得依赖 v3/ 的运行时代码。
- V1 交易/回测系统及 backtest_system/ 不得修改。
- 迁移必须包括核心判断、Bitget 行情适配、ntfy 摘要与去重、扫描入口、测试及 GitHub Actions 调度。
- 在 V4 测试和工作流确认通过、扫描入口完成切换之前，不删除 V3 文件；防止出现无可运行版本的空窗。
- V3 删除范围必须包含其专用代码、测试、A 股旧目录与只服务 V3 的工作流/调度引用；删除前核对共享配置与 V1 依赖，不能误删 V1。
- 本文件记录规则与迁移要求，不代表运行、推送或部署已经通过验证。
