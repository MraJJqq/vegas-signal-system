# VEGAS V9 规则说明

## 核心信号规则
- **观察期：** 使用已收盘的 4H K 线；触及中锋 EMA144/169 或红峰 EMA576/676 后进入观察期。观察期不限时，离开均线区域不取消。
- **信号期：** 观察期触发后，等待后续已收盘的原生 2H K 线；比较 2H 收盘价与 2H EMA12。收盘价在 EMA12 上方或下方均产生正式信号，不判断方向；等于 EMA12 不确认。
- 每轮观察期最多产生一次正式信号；确认后退出观察状态。
- 4H 负责观察期触发，2H EMA12 负责信号期确认。按 K 线收盘时间顺序处理事件，避免使用触碰前的 K 线确认。
- 仅纳入中国时区当天的正式信号；数据错误或无已收盘 K 线的品种排除本轮扫描。
- 固定扫描池共 27 个：BTC、HYPE、XAU、CL，以及 AAPL、MSFT、GOOGL、AMZN、NVDA、TSLA、META、INTC、QCOM、AMD、TSM、AVGO、ORCL、ARM、MU、ASML、SNDK、SKHYNIX、MRVL、GLW、HOOD、CBRS、SPCX。
- 数据源：Bitget USDT 永续合约；观察期使用 4H 指标，信号期使用原生 2H K 线及 2H EMA12。

## 隔离与验证
- V9 独立放在 v9/；V8 目录和工作流保持不变。
- V9 使用独立信号状态文件与报告文件。
- 修改后应通过 Python 编译与信号逻辑单元测试。
